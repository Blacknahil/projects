# Tutor Linkup

## Description
The tutor link up website will cater to students of all ages, ranging from primary school to university level. 
It will serve as a centralized hub for connecting students with qualified tutors across different subjects. 
This website aims to facilitate a platform where students or parents can find suitable tutors for various subjects and academic levels.


## Unique Features.
The tutor linkup website will replace traditional way of searching for tutors and reduces the cost that tutors have to spend by preparing 
flyers and banners to post on walls. This platform is different from the existing platforms that on work on this field because it is free and
opens opportunity for campus students to work part time according to their schedule and location.
Additionally, other existing platforms work as an agent instead of connection purpose.
